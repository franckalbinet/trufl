Callbacks

Describe each area by state variables, such as the maximum, the number of measurements or Moran’s I, computed by callbacks from the measurements collected so far.

A State describes every area by a set of variables computed from the measurements collected so far. Each callback computes one variable, such as the highest value (MaxCB) or the number of measurements (CountCB). Calling a State runs every callback on every area and returns one row per loc_id. Optimizer ranks the areas from this table.

Callbacks

Each callback below computes one variable per area. MaxCB, MinCB, StdCB, CountCB and MoranICB return NaN for an area without measurements. A missing count is therefore NaN, not 0. Optimizer.get_rank treats a missing value as the highest priority for its criterion.

To add a variable, subclass Callback and implement __call__(loc_id, o). Return a tuple of Variables to add several columns at once.

MoranICB

def MoranICB(
    k:int=5, # Number of neighbours per point, used to expand the measurements and to build the spatial weights
    p_threshold:float=0.05, # Significance level: Moran's I is `NaN` when its pseudo p-value `p_sim` is at or above it
    name:str='Moran.I', # Name of the variable
    min_n:int=5, # Areas with `min_n` measurements or fewer get `NaN`
):

Moran’s I of the area’s measurements and their nearest neighbours. NaN if the area has too few measurements or Moran’s I is not significant.

source

PriorCB

def PriorCB(
    fname_raster:str, # Raster used as the prior
    name:str='Prior', # Name of the variable
):

Mean of fname_raster over the area, emulating prior knowledge such as an airborne survey. Computed for every area, measured or not.

Example

The example emulates one campaign on a 10 by 10 grid. Each area gets between 0 and 9 points:

fname_raster = 'files/ground-truth-01-4326-simulated.tif'
gdf_grid = gridder(fname_raster, nrows=10, ncols=10)
n = np.random.default_rng(41).integers(0, 10, size=len(gdf_grid))
samples_t0 = DataCollector(fname_raster).collect(Sampler(gdf_grid).sample(n, method='uniform', rng=41))
ax = samples_t0.plot(column='value', s=3, legend=True)
gdf_grid.boundary.plot(color=black, lw=0.5, ax=ax)
ax.axis('off');

Create a State with the callbacks to compute, then call it to get one row per area. MoranICB tests significance with random permutations. Fixing NumPy’s global seed makes its results reproducible:

np.random.seed(0)
state = State(samples_t0, gdf_grid, cbs=[
    MaxCB(), MinCB(), StdCB(), CountCB(), MoranICB(k=5), PriorCB(fname_raster)
])
state_t0 = state()
test_eq(len(state_t0), len(gdf_grid))

Expanding measurements for Moran’s I

Moran’s I measures spatial autocorrelation. It is close to 1 when nearby measurements have similar values, and close to 0 when values are spatially random. One area rarely has enough measurements to estimate it alone. MoranICB therefore adds the k nearest measurements of each point in the area, including those in neighbouring areas. expand_to_k_nearest does this expansion.

The plot shows the expanded measurements of the area with the most measurements, and the areas they come from:

loc_id = state_t0['Count'].idxmax()
subset = state.measurements.loc[[loc_id]]
expanded_pts = state.expand_to_k_nearest(subset, k=5)
test_eq(len(expanded_pts), 5 * len(subset))
ax = expanded_pts.plot(column='value', s=10, legend=True)
gpd.sjoin(gdf_grid, expanded_pts, how="inner", predicate='contains').boundary.plot(color=black, lw=0.5, ax=ax)
ax.axis('off');
